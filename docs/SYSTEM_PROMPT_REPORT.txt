1) INTERNAL VERSION (Technical)
==================================================

Objective
- Deliver MVP aligned with manual template v2: A1..F8 questionnaire, six-dimension job vectors,
  numeric ranking lock, top_5 output, and explanation-only LLM role.

Implementation
- Python scorer (backend/scorer.py): user vector from 48 items, mean-distance score, tie-break.
- Explanation prompts (backend/prompt_templates.py); Gemini/OpenAI (backend/llm_service.py).
- Sheets pipeline (backend/sheets_client.py): Responses A1..F8, Results vector + top_jobs + summary.
- API v2 (backend/main.py); results UI (frontend/results.html).
- Tests: 22 passing; scorer benchmark via scripts/run_benchmark.py -> data/benchmark_results/.

Production vs manual JSON
- Runtime stores user_dimension_vector, top_jobs (job_id, job_label, score, reason), summary.
- Manual annex / notes_for_reviewers are for model testing, not persisted in MVP API or Sheets.

Gaps

2) CLIENT VERSION (Non-technical)
==================================================

What was delivered
- A career test flow: form answers in Google Sheets, automatic processing, top five job matches
  with short reasons, and a results page.

What is fixed
- Ranking uses one transparent formula on six interest dimensions.
- AI text explains matches; it does not change the order or scores.
- Close results use a defined tie-break sequence.

Validation
- Six benchmark profiles and automated tests on the core 30-job set.
- Operator setup and sample data are documented in README.md.

Next steps
